# Helmet Detection Portal using YOLOv8

A Flask-based computer vision web application for detecting helmet usage in images using a YOLOv8 model. This project focuses on traffic safety monitoring and demonstrates real-time inference through a simple web interface.

---

## Features
- Image upload through a web portal
- Helmet detection using YOLOv8
- Annotated output with bounding boxes
- Flask-based backend for inference

---

## Tech Stack
- Python
- YOLOv8 (Ultralytics)
- OpenCV
- Flask

❌ Error (What’s happening)
ValueError: signal only works in main thread of the main interpreter
Why this happens
You are running Flask with debug=True

Flask’s auto-reloader uses signal

Your app is being run inside another thread/process
(often happens with:

threading

multiprocessing

running Flask from another script / notebook

some ML/video processing loops)

👉 Signals only work in the main thread, so Flask crashes.

✅ QUICK FIX (Recommended)
🔹 Change this line:
app.run(debug=True)
🔹 To this:
app.run(debug=False)
OR (even better):

app.run(debug=True, use_reloader=False)
✅ This disables the reloader that causes the error.

if __name__ == "__main__":

🧠 Why this works
use_reloader=False stops Flask from spawning another process

Keeps everything in the main thread

Safe for:

OpenCV

YOLOv8

OCR

ML models

    # Resize frame

    # Convert to grayscale
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

    # Noise reduction
    gray = cv2.bilateralFilter(gray, 11, 17, 17)

    # Edge detection
    edged = cv2.Canny(gray, 170, 200)

    # Find contours

            break

        x, y, w, h = cv2.boundingRect(number_plate_cnt)
